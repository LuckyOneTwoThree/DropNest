## 目录

## 一、产品定位与本期目标 🎯

- **产品定位**：住在刘海里的便捷巢——closed 态为媒体信息监听条，open 态为文件暂存架
- **本期目标**：从「刘海暂存」扩展为「随处可存、自动留存、成组规整」
- **核心架构思想：万物皆入巢** —— 一个统一数据模型（NestItem）、两个新入口（摇晃悬浮框、剪贴板监听）、一种组织方式（集合）

## 三、需求一：剪贴板历史 📋 ✅（已完成）

### 3.1 用户场景

复制了 A → 又复制了 B → 突然需要 A → 不用回原文档重新复制，从巢里点一下就回来。

### 3.2 功能点清单

| 编号 | 功能点 | 说明 | 优先级 |
| --- | --- | --- | --- |
| FR-C1 | 剪贴板监听 | 轮询 NSPasteboard.changeCount（250–500ms），变化即捕获 | P0 |
| FR-C2 | 文本条目 | 纯文本/富文本入巢，网格中显示预览摘要 | P0 |
| FR-C3 | 文件条目 | Finder 复制文件 → 映射为 .file(bookmark) 条目（复用 Shelf 书签机制，不复制实体文件） | P0 |
| FR-C4 | 链接条目 | URL 识别为 .link 条目 | P0 |
| FR-C5 | 图片条目 | 截图/图片复制入巢，异步生成缩略图 | P1 |
| FR-C6 | 历史上限 | 可配置 10/25/50/100 条，LRU 淘汰 | P0 |
| FR-C7 | 去重 | 相同内容复制 → 上移置顶而非新增 | P0 |
| FR-C8 | 隐私排除 | 遵守 ConcealedType/TransientType 约定（密码管理器标记）；可配置排除应用列表 | P0 |
| FR-C9 | 取回 | 点击条目写回剪贴板（文件用 writeObjects），用户自行 ⌘V | P0 |
| FR-C10 | 钉选 | pinned 条目不参与淘汰 | P1 |
| FR-C11 | 清理 | 一键清空；可选「重启即清空」 | P1 |
| FR-C12 | 搜索 | 按内容/类型筛选搜索 | P2（本期不做） |
| FR-C13 | 自动粘贴 | 选择即模拟 ⌘V 粘贴到目标 App | P2（不做：需辅助功能权限，违背零权限原则） |

### 3.3 展示位置

- 条目直接混入 Shelf 网格，角标区分来源（拖入/复制）
- 顶部轻量筛选：全部/文件/文本/链接
- Maccy 式独立热键弹窗 → P2 二期（随热键体系回归）

### 3.4 验收标准

- [x]  复制文本/文件/链接后 1 秒内出现在 Shelf
- [x]  达到上限后最旧未钉选条目被淘汰
- [x]  密码管理器标记内容（1Password 等）不入历史
- [x]  点击文件条目后可在 Finder/任意 App ⌘V 粘贴成功（含多文件场景）
- [x]  重启 App 后历史保留（可选配置清空）
- [x]  全流程无新增系统权限请求

## 四、需求二：悬浮暂存巢群（巢即集合）🪟

### 4.1 用户场景

拖着文件出发 → 桌面上已有的暂存巢进入可接收高亮态、鼠标附近同时出现一个浅色「空巢胚」→ 拖进既有巢 = 加入那个集合；拖进空巢胚 = 孵化出一个新集合；都没用上 → 空巢胚静默消失。「仅摇晃召唤」模式下，晃一晃鼠标手动唤出空巢胚。

### 4.2 功能点清单

| 编号 | 功能点 | 说明 | 优先级 |
| --- | --- | --- | --- |
| FR-F1 | 摇晃检测 | 拖拽中采样 mouseLocation，时间窗内方向反转 ≥3 次判定；灵敏度可调（「仅摇晃召唤」模式的手动入口） | P0 |
| FR-F2 | 悬浮暂存巢 | NSPanel（non-activating + floating）；每个巢 = 一个集合（groupID）；出现在指针附近，屏幕边缘自动校正 | P0 |
| FR-F3 | 共享数据源 | 与刘海 Shelf 共用 ShelfStateViewModel 单例，双边实时同步 | P0 |
| FR-F4 | 生命周期 | 空巢胚：拖拽结束未使用即销毁；正式巢：可收起回刘海、位置按组记忆 | P0 |
| FR-F5 | 触发方式 | 设置项二选一：拖拽开始自动显示巢群（默认）/ 仅摇晃召唤；灵敏度可调 | P0 |
| FR-F6 | 多巢并存 | 桌面可同时存在多个巢；拖拽期间已有巢进入可接收高亮态 | P0 |
| FR-F7 | 空巢胚 | 拖拽期间若无空巢则生成浅色空巢胚（45% 透明度 + 虚线描边）；drop 即孵化；未用即消失 | P0 |
| FR-F8 | 网格自适应 | n×n 正方形网格（2~4 个 → 2×2；上限默认 3×3、设置项可调）；超出纵向滚动；窗口随网格自适应尺寸 | P0 |
| FR-F9 | 全局热键召唤 | 非拖拽场景手动唤出 | P2（二期） |

### 4.3 验收标准

- [ ]  拖拽开始后 300ms 内：已有巢进入可接收高亮态；若无空巢胚则鼠标附近出现浅色空巢胚
- [ ]  拖入空巢胚 → 孵化为正式巢并成为新集合；拖入既有巢 → 加入该巢集合
- [ ]  拖拽结束未使用空巢胚 → 空巢胚自动消失，不留痕迹
- [ ]  巢网格按内容数自适应（2~4 个 → 2×2；5~9 个 → 3×3；超出纵向滚动），上限可在设置中调整
- [ ]  「仅摇晃召唤」模式下：拖拽中摇晃指针 500ms 内出现巢；连续使用 10 分钟 0 误触发
- [ ]  拖入巢的文件立即出现在刘海 Shelf（双向同步）
- [ ]  巢不夺取焦点（当前 App 保持激活）；全流程无新增系统权限

## 五、需求三：集合（巢群）🪺

### 5.1 立项依据（竞品空白）

- Yoink 有 Stack 但无多悬浮窗、无刘海集成；Dropover 有多悬浮窗但集合是隐式的、刘海仅是拖放入口；NotchNook 连多选拖出都不支持
- 「集合一等公民 + 刘海 ⇄ 桌面双向流转」无产品覆盖 → 差异化立项

### 5.2 功能点清单

| 编号 | 功能点 | 说明 | 优先级 |
| --- | --- | --- | --- |
| FR-N1 | 集合模型 | ShelfItem 增加 groupID；同组聚合渲染为集合卡片 | P0 |
| FR-N2 | 集合卡片 | 叠层缩略图 + 数量角标，与单文件混排；悬浮巢成组内容在刘海 Shelf 同样以组卡片聚合展示（不拆散） | P0 |
| FR-N3 | 成组 | 拖入既有巢 = 加入该巢集合（默认语义）；拖到 Shelf 现有条目上入组；多选右键「组成集合」 | P0 |
| FR-N4 | 整体拖出 | 拖集合卡 = 组内全部 fileURL 写入同一 drag session（复用现有多选拖拽） | P0 |
| FR-N5 | 解散/就地查看 | 右键解散集合；右键就地查看组内条目 | P0 |
| FR-N6 | 多巢并存 | 桌面可同时多个悬浮巢，FloatingNestManager 统一管理 | P0（提前自 Sprint 3） |
| FR-N7 | 收纳（分巢 → 总巢） | 单个巢「收起」按钮收回刘海；文件架一键全部收起 | P0（提前自 Sprint 3） |
| FR-N8 | 分巢（总巢 → 桌面） | 点击 Shelf 组卡片 = 该组以悬浮巢展示；文件架一键展开全部 | P0（提前自 Sprint 3） |
| FR-N9 | 集合命名/颜色 | 重命名与颜色标记 | P1 |
| FR-N10 | 位置记忆/闲置淡化 | 巢位置按 groupID 记忆并还原（P0）；闲置透明度降低（P1） | P0 / P1 |
| FR-N11 | 一批拖入自动成组 | 同批拖入同一巢的条目天然共享该巢 groupID（默认语义，无需开关） | P0 |

### 5.3 验收标准

- [ ]  多文件拖到 Shelf 已有条目上即入组，卡片显示数量角标
- [ ]  拖集合卡到 Finder 目标位置，组内文件全部一次性到位
- [ ]  解散集合后条目恢复为独立单文件
- [ ]  桌面多个巢并存互不干扰；刘海 Shelf 中集合以组卡片聚合展示
- [ ]  文件架可一键展开全部巢 / 一键全部收起；单个巢可收起回刘海
- [ ]  点击 Shelf 组卡片 → 该组以悬浮巢展示在桌面（位置取记忆值）
- [ ]  重启后集合关系与巢位置保留

## 七、非功能需求 ⚙️

| 类别 | 要求 |
| --- | --- |
| 权限 | 零新增系统权限：摇晃=mouseLocation 轮询；剪贴板=changeCount 轮询；取回=写回不模拟按键 |
| 隐私 | 密码管理器标记内容必须排除；排除应用列表；一键清空历史 |
| 性能 | 轮询为整数比较，开销可忽略；多悬浮窗共享单例数据源 + groupID 过滤，避免视图树重复 |
| 兼容 | macOS 14+；沙盒合规；复用现有 bookmarks 持久化机制 |
| 架构 | 悬浮窗窗口族与「每屏一个刘海窗口」体系隔离，由 FloatingNestManager 独立管理 |

## 八、分期与里程碑 🗺️

1. **Sprint 1（P0）✅ 已完成**：剪贴板 MVP —— FR-C1~C4、C6~C9
2. **Sprint 2（P0）👈 当前**：集合闭环（FR-N1~N5）+ 悬浮巢群（FR-F1~F8）+ 刘海⇄桌面流转（FR-N6~N8、N10 位置记忆、N11）

## 九、技术风险与注意 ⚠️

1. **摇晃检测误触率**：需实机调参（幅度/频率/时间窗阈值），验收标准含 10 分钟 0 误触发
2. **多文件写回剪贴板**：writeObjects 有坑，直接参考 Maccy 的 Clipboard.swift 处理
3. **Universal Clipboard**：跨设备复制会产生重复条目，参考 Maccy 的去重过滤
4. **集合整体拖出**：与现有 DraggableClickView 多选拖拽逻辑的合并方式需先定方案
5. **窗口体系隔离**：多巢与 showOnAllDisplays 的刘海窗口逻辑不得互相干扰
6. **空巢胚出现时机**：依赖 DragDetector 的内容拖拽判定（drag pasteboard changeCount），文本/URL 拖拽同样要覆盖；多屏时按 point 所在屏校正
